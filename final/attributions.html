Images

All spacecraft images sourced from NASA Image Gallery, Wikimedia Commons, and ESA Media Library under public domain or Creative Commons licenses. Images resized and optimized for web use.

Real-time images from NASA Images API (https://images-api.nasa.gov) are fetched asynchronously to enrich the spacecraft cards with high-quality official NASA photography.

Fonts

Typography provided by Google Fonts: Orbitron (display), Share Tech Mono (monospace), and Barlow (body text).

APIs Used

This project demonstrates integration of the NASA Images API (https://images-api.nasa.gov/search), a free, publicly available service that requires no authentication. The API provides access to millions of high-quality photographs from NASA's image collection.
